# Usarim Tech Store

Simple tech store website made with Bootstrap and little bit CSS.
This is a student project, coded manually in VS Code.

## Pages (4 pages)
1. index.html - Home page
2. products.html - Products page (earpods, headphone, smart watch etc)
3. about.html - About page
4. contact.html - Contact page

## How to open in VS Code
1. Extract the zip file
2. Open the folder in VS Code (File > Open Folder)
3. Open index.html and click "Go Live" or just double click index.html in browser

## How to upload on GitHub
1. Go to github.com and login
2. Click New Repository, name it `usarim-tech-store`, click Create
3. Click "uploading an existing file"
4. Drag all files and the css folder from this folder
5. Click Commit changes
6. For live link: Repo Settings > Pages > Branch: main > Save
   Your site will open like: https://your-username.github.io/usarim-tech-store/

Note: Product pictures are online images (Unsplash links), so internet is needed for pictures.
Form on contact page is only front-end, it does not send message.
